# Демо-сайты ресторанов и баров (Москва)

50 демо-сайтов для заведений, у которых нет сайта в карточке Яндекс Карт. Собраны как визитки:
фото, меню с ценами из карточки, отзывы, адрес и кнопка брони (WhatsApp или звонок).

Каждый сайт — папка в `sites/<key>/index.html`. Список всех заведений с адресами,
телефонами и ссылками на карточки — в [sites/CLIENTS.md](sites/CLIENTS.md).

**Это демонстрационные материалы для питчинга**, не готовые к продакшену:
- фото взяты с Яндекс Карт только для показа, для публикации нужны фото владельца;
- перед боевым запуском см. `tools/README.md` (домен, индексация, форма брони).

## Живые ссылки

Если включён GitHub Pages, каждый сайт открывается по адресу вида:
`https://koky09.github.io/sites-restaurants/sites/<key>/`

## Структура
- `sites/` — 50 готовых сайтов + `CLIENTS.md`
- `tools/` — генератор сайтов (Python): `specs.py` (тексты и дизайн), `kit.py` (конструктор блоков),
  `build.py` (сборка, SEO, оптимизация фото), `discover.py` (поиск заведений на Яндекс Картах)
