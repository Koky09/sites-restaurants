# Индивидуальные сайты ресторанов (own/)

Цель (07.11.2026): ещё 100 сайтов к первой десятке. Рассылка только по команде пользователя, в Telegram не больше 8–10 новых в день.

Порядок работы над партией из 10:
1. `python tools/own_fetch.py key=начало названия ...` — данные в `data/own/<key>.json`, фото в `raw/own/<key>/`, лист `raw/own/_sheets/<key>.jpg`.
2. Посмотреть листы, отобрать только свои кадры (в конце списка бывают чужие «похожие места»), дописать номера в `PICK` в `tools/own_img.py`, запустить `python tools/own_img.py <key ...>`.
3. Написать `own/<key>/index.html` вручную: своя идея, своя вёрстка, свои шрифты. Подключить `../booking.js` и `../fx.js`, задать `window.OWN`.
4. `python tools/own_check.py <key ...>` и посмотреть снимки первых экранов в `raw/own/_check/`.
5. Когда партии готовы: `python tools/own_video.py <key ...>`, дополнить `REST` в `tools/own_outreach.py`, выложить `git push`, проверить живые ссылки, обновить страницу рассылки.

Правила, выученные на ошибках:
- Только шрифты с кириллицей. Нельзя для русского текста: Bebas Neue, Cinzel, Bodoni Moda, Karla, Great Vibes (только латинские слова).
- В CSS сайта не использовать без родителя классы брони: `.row .wrap .plan .tb .lb .sub .go .err .c .x .done`, иначе ломается окно брони (проверка это не всегда ловит).
- Не писать непроверенное («ручная лепка», «рядом с центром»). Брать факты из карточки, меню и отзывов. Нет меню — блюда из отзывов без цен и пометка «добавим из вашего прайса».
- Подписи блюд должны совпадать с фото.
- Поиск: `tver-demo/tools/newclient/find_rest2.py` -> `rest2-found.json`; короткий список `rest2-short.json`; проверка скрытых сайтов `rest_verify.py` -> `rest2-verified.json` (поле `own_site`). Находка из справочника не считается сайтом, но настоящие сайты и сервисы брони (restoplace, rsrv.rest, tilda) отсеиваются.
- Telegram Web работает только в одной вкладке: «App is inactive» значит, открыта другая.
